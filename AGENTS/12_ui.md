# PROMPT 12: templates/ - Frontend CRM del Restaurante

## Objetivo
Crear todos los templates HTML para el CRM del restaurante usando Jinja2 + Tailwind CSS.

## Instrucciones Detalladas

Crear la estructura de templates:

```
templates/
├── base.html
├── dashboard.html
├── inbox.html
├── clientes.html
├── cliente_historial.html
├── pedidos.html
├── reservas.html
├── menu.html
├── promociones.html
├── delivery.html
├── analytics.html
├── ai_intelligence.html
├── ai_governance.html
├── configuracion.html
└── partials/
    ├── sidebar.html
    ├── header.html
    └── footer.html
```
