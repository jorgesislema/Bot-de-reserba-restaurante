# Guia de Usuario - Restaurant AI Platform

## Como usar el chatbot

### WhatsApp
1. Envia un mensaje al numero del restaurante
2. El bot te ayudara con pedidos, reservas, menu, etc.
3. Si necesitas un humano, el bot te conectara

### Telegram
1. Busca el bot en Telegram
2. Envia un mensaje
3. Sigue las instrucciones del bot

## Funcionalidades

### Consultar Menu
- "Que pizzas tienen?"
- "Cual es el precio de la hamburguesa?"
- "Tienen opciones sin gluten?"

### Hacer un Pedido
- "Quiero una pizza familiar"
- "Agrega una Coca-Cola"
- "Confirmar pedido"

### Hacer una Reserva
- "Quiero reservar para 6 personas"
- "Para manana a las 8pm"
- "A nombre de Carlos Perez"

### Delivery
- "Hacen delivery?"
- "Cuanto cuesta enviar a Av. Principal?"
- "Seguimiento de mi pedido"
